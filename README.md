Berikut adalah alur flowchart dari mini project saya yang berupa Sistem Pengelolaan Data Penyewaan Game Digital (GameCloud).

<img width="1571" height="822" alt="Screenshot 2026-09-12 211606" src="https://github.com/user-attachments/assets/11bab0f5-dcd8-4ebc-b69d-99b394c17a59" />

Nah, dibagian pertama ini program dimulai dari start. Setelah itu anda sebagai admin diminta untuk melakukan registrasi dengan membuat username dan password admin terlebih dahulu.
Tujuannya supaya akun admin kita bisa tersimpan dan bisa digunakan saat login.

Setelah regis, anda akan diminta untuk login dengan memasukkan user dan password yang sudah anda buat. Setelah login nanti akan ada Menu GameCloud khusus untuk admin yang berisi 9 pilihan. Mulai dari menambah data penyewaan, melihat data, mengubah data penyewa, mengubah status pembayaran, memperpanjang durasi sewa, mencari data penyewa, menghapus data penyewa, mengelola game penyewa, sampai menu selesai.

<img width="1321" height="869" alt="Screenshot 2026-09-12 211925" src="https://github.com/user-attachments/assets/f6ccb26e-d3ba-4979-ac8a-8896be0dfdad" />

Ini adalah contoh menu 1 yaitu penambahan data penyewa, anda bisa mengetik nama penyewa terlebih dahulu, setelah itu anda bisa memasukan game sesuai yang ingin disewa oleh pelanggan, menentukan durasi penyewaan, lalu harga akan dihitung secara otomatis dan sistem akan menyimpan data dengan status Belum Dibayar.



<img width="805" height="840" alt="Screenshot 2026-09-12 211953" src="https://github.com/user-attachments/assets/5cc445f7-56ed-42e0-ae4f-b9fe3cb43c3d" />

Selanjutnya adalah contoh menu 2, menu ini bisa anda gunakan untuk melihat data penyewa yang sudah tersimpan. Nantinya program akan menampilkan nama penyewa, daftar game yang disewa, durasi setiap game, total biaya, dan status pembayarannya.



<img width="1081" height="1135" alt="Screenshot 2026-09-12 212020" src="https://github.com/user-attachments/assets/4e42e9b9-3c4c-47a7-af93-fe6a85e4b917" />

Di menu 3 ini anda bisa memilih penyewa yang ingin diubah, nama penyewa bisa diganti dan salah satu game yang disewa juga bisa diganti dengan game lain dan setelah selesai, data akan diperbarui


<img width="782" height="378" alt="Screenshot 2026-09-12 212039" src="https://github.com/user-attachments/assets/fb775671-ac15-48ac-bf6d-0a8d31d24965" />

Nah, pada menu 4 ini kalian bisa mengubah status pembayaran penyewa menjadi sudah dibayar atau belum sesuai dengan pelanggan yang sudah membayar atau belum.


<img width="894" height="465" alt="Screenshot 2026-09-12 212059" src="https://github.com/user-attachments/assets/e9345e3a-b2cc-4df3-aaa0-a445bff58a81" />

Pada menu 5 ini anda bisa memilih penyewa dan memilih game yang ingin diperpanjang masa sewanya, anda bisa menambahkan durasi satu hari, satu minggu atau satu bulan. Durasi sebelumnya akan ditambahkan dan tidak diganti, total biaya juga ikut bertambah tentunya.


<img width="1186" height="745" alt="Screenshot 2026-09-12 213129" src="https://github.com/user-attachments/assets/55d94274-89e6-40c3-83c4-e7173ebbed79" />

Menu 6 ini bisa anda gunakan untuk mencari data penyewa, jika nama ditemukan maka program akan menampilkan seluruh informasi penyewaan dan jika tidak ditemukan maka akan muncul pesan bahwa data penyewa tidak ada.



<img width="600" height="343" alt="Screenshot 2026-09-12 212243" src="https://github.com/user-attachments/assets/62ef3ddf-d7ad-4bbd-98a0-35fe0588dbf0" />


Selanjutnya, di menu 7 ini anda akan diberikan dua pilihan yaitu menghapus satu data penyewa atau menghapus seluruh data penyewaan. jika memilih hapus semuanya maka program akan mengkonfirmasi dulu agar data tidak terhapus secara tidak sengaja.


<img width="1358" height="974" alt="Screenshot 2026-09-12 212337" src="https://github.com/user-attachments/assets/aa7e351c-67ac-4025-9de0-f399b1f6647c" />


Nah selanjutnya menu 8 bisa anda gunakan untuk mengelola game milik penyewa, anda bisa menambahkan game baru, menghapus salah satu game, atau menghapus semua game yang dimiliki penyewa. Setelah perubahan dilakukan nantinya total biaya penyewaan akan diperbarui secara otomatis.



<img width="1011" height="687" alt="Screenshot 2026-09-12 212351" src="https://github.com/user-attachments/assets/f4a701e0-701e-44a8-b4d2-24a0828e2e29" />


Nah, yang terakhir program akan menampilkan ringkasan seluruh data penyewaan, termasuk jumlah penyewa, jumlah yang sudah atau belum membayar, serta total pendapatan dari penyewa yang statusnya sudah dibayar. Setelah itu program selesai dan keluar.
